07Sweep

曲げる、巻く、絞る

sweep along a spine — 軸に沿った掃引

この章の3行まとめ
  • バナナはまっすぐではありません。中ほどがいちばん強く弓なりに曲がっています。
  • 回転体では作れないので、先に軸（背骨）を決め、断面を軸に垂直に置いていきます。これを掃引といいます。
  • 軸を円にすればロールケーキの側面、螺旋にすれば絞り出しクッキー。軸と断面の組み合わせで、曲げる・巻く・絞るが全部書けます。

チョコバナナを作ります。バナナを回転体で作ると、まっすぐな棒になります。 実物はまっすぐではありません。しかも、むいた実の断面は丸ではなく、 4〜5本のゆるい稜が残っています。チョコバナナ.js の冒頭のコメントにこうあります。

「バナナは真っ直ぐではなく弧。しかも断面は丸ではなく、むいた実でも 4〜5 本のゆるい稜が残る。 コーティングで稜は鈍るが消えはしない。チョコは『先端を下にして』引き上げて垂らすので、 先端側ほど厚く、先端に滴が溜まり、先端へ向かって縦の垂れ筋が残る」

そこで作り方を変えます。まず軸（スパイン、中心線）を1本決めます。 次に、軸上の各点で「そこでの断面」を作り、軸に垂直な平面の上に置きます。 これを軸に沿って何十枚も並べ、隣どうしをつなげば立体になります。これを掃引といいます。

実験 — 軸を曲げて、断面を並べる

「断面の輪を描く」を押すと、軸に垂直な平面が何枚も並んでいるのが見えます。 曲がりの初期値 1.85 はチョコバナナ.js の値です。0.95 まで下げると「太いきゅうり」に戻ります。 「先端の垂れ」は「チョコを掛けた」のときだけ効きます。右（先端）ほどチョコが厚くなります。
立体はドラッグで回せます（触ると自動回転は止まります。ダブルクリックで戻ります）。 真上から見ると、軸の曲がりがそのまま輪郭に出ているのが分かります。

曲がりは、一定ではない

最初に思いつくのは、円の一部（一定の曲がりの弧）を軸にすることです。チョコバナナ.js の記録： 「一定曲率の弧だと定規で曲げたパイプに見える。実物は中ほどが最も曲がり、両端は比較的まっすぐ」。 そこで、軸の向きの角度を位置 s の関数にして、真ん中で変化が速くなるようにしています。 曲がりの量そのものにも記録があり、「0.95 では全体で 40° しか曲がらず、太いきゅうりに見えた」ので、 いまは 1.85 です。掃引で作る形は、軸のどこがどれだけ曲がっているかがほとんどすべてです。

両端と、塗り厚の閉じ方

掃引で作った筒は、両端が開いています。バナナは端で半径を 0 まで絞って閉じますが、 そこにチョコの厚みを「一定のまま」足すと、半径 0 のはずの端に厚みだけが残って穴があきます。 チョコバナナ.js は塗り厚に、太さの形の平方根 √env を掛けて、端では必ず 0 に落としています。 さらに、端は曲がりが急なので、断面の輪を等間隔に並べると先端が角ばる。 そこだけ輪の間隔を詰めています。

軸を閉じると「巻く」、螺旋にすると「絞る」

軸は開いた弧である必要はありません。

  • ロールケーキ — 切り分けた1切れを、「断面 → 面取り → 側面 → 面取り → 断面」と1枚の格子で掃引しています。 ロールケーキ.js の記録：「断面と側面を別メッシュにすると、隙間・蓋の欠け・片側だけの裏返りが同時に起きる」。 断面の渦巻きは、線ではなく巻いたシートとして断面関数に書いてあり、形とテクスチャが同じ関数を引きます。
  • 絞り出しクッキー — 星口金から出た生地は、星形の断面（山が8つ）を螺旋の軸に沿って掃引したものです。 クッキー.js には、巻きどうしが必ずくっつく条件が書いてあります。「半径方向のピッチ < 縄の太さ」。 ピッチ 0.70cm に対して太さ 1.20cm で、重なったところが深さ約1mmの螺旋の溝として残ります。

曲げる・巻く・絞るは、お菓子作りでは別の作業ですが、コードでは同じ掃引です。 違うのは軸の形と断面の形だけです。

つまずきポイント

断面の向きは、勝手に決まってくれません。 軸に垂直な平面は、軸のまわりに無数の回り方ができます。 よくある「毎回、真上（UP）との外積で決める」やり方は簡単ですが、 軸が真上を向いた瞬間に外積が 0 になって破綻し、断面がねじれます。

チョコバナナ.js は、この問題を形の側で避けています。中心線はいつも YZ 平面の中にあるので、 X 軸は必ず軸に垂直です。そこで断面の向きを N = X × T（T は軸の向き）で決めれば、 どれだけ曲げても破綻しません。螺旋のように平面に収まらない軸では、 前の断面の向きを少しずつ引き継ぐ方法（平行移動枠）を使います。

やってみよう
  1. 曲がりを 0 にして、チョコバナナが何に見えるか判定する。
  2. 稜の強さを 0 と 0.12 にして、むいた実に見える範囲を探す。
  3. 「チョコを掛けた」で先端の垂れを 1 にし、輪を描いて、先端側の断面が太っていることを確かめる。
  4. チョコバナナ.js で「√env」の近くを読み、塗り厚が端でどう 0 に落ちているか確かめる。
