00START

まず動かしてみる

読む前に、動かす。5分で終わります

この章の3行まとめ
  • この9本は、ブラウザだけで動きます。インストールは何も要りません。
  • Babylon.js Playground という公式サイトに、ファイルの中身をまるごと貼って実行するだけです。
  • 先に動かして、数字をひとつ壊してみる。説明を読むのはそのあとのほうが、ずっと早く分かります。

このプロジェクトの .js ファイルは、ふつうの Web ページに読み込んで使うものではありません。 Babylon.js Playground（バビロン・ジェイエス・プレイグラウンド）という、 ブラウザの中で3Dのプログラムを書いて即座に実行できる公式サイトのための形になっています。

いきなり動かしたいだけなら。 図鑑の写真を押すと、このサイトの中でそのまま動きます。 貼り付けの手順を踏むのは、数字を書き換えて遊びたくなってからで十分です。

  1. Playground を開く

    playground.babylonjs.com をブラウザで開きます。左が入力欄、右が3Dの画面です。 パソコンのほうがやりやすいですが、スマホでも動きます。

  2. もとから入っているコードを全部消す

    左側をクリックして、Ctrl+A（Mac は ⌘+A）で全選択 → Delete。 まっさらにしてから貼るのがコツです。混ざると動きません。

  3. 花見団子.js の中身を全部コピーして貼る

    最初の1本は 花見団子.js がおすすめです。9本のなかでいちばん短く、物理エンジンも使いません。 「球を串の方向に少し潰して、竹串に刺す」だけでできています。 ソースを読むのページに 「コードをコピー」ボタンがあるので、それを押して Playground の左側に貼り付けます。

  4. 実行する

    上の Run ボタン（または Alt+Enter）。 数秒〜十数秒待つと、皿の上に団子の串が出てきます。 右下にスライダーが出るので、動かしてみてください。

    うまくいかないとき

    真っ黒のまま／なかなか出てこない — このプロジェクトは模様を画像として読み込まず、 実行するたびに 1ピクセルずつ計算して描いています。1024×1024 を何枚も焼くので、 出るまでに十数秒かかるサンプルがあります（チョコレートとパンケーキが特に長い）。まず待ってみてください。

    エラーが出る — 貼り付けたときに古いコードが残っていないか確認してください。 物理エンジン（Havok）を使うサンプルは、その読み込みにも数秒かかります。

    動きがカクカクする — 3Dの計算をパソコンが全部やっています。 ブラウザの他のタブを閉じると軽くなります。

  5. 数字をひとつ、わざと壊す

    ファイルの上のほうにある PRESETS の中から glaze（たれの量）や scorch（焼き目）を探して、思いきり大きな値に書き換えて Run。 どの数字が何に効くかは、壊すといちばん早く分かります。 壊してしまっても、もう一度コピーして貼り直せば元どおりです。

  6. 中身を覗いてみる（Inspector）

    Playground の右上にある Inspector を開くと、いま動いているシーンの中身が全部見えます。 左の Scene Explorer がメッシュ・材質・テクスチャの一覧、右がその設定です。 照準のボタン（Picker）を押してから画面のお菓子をクリックすると、 いま押したものがツリーのどれなのかを教えてくれます。

    ここで値を触ると、コードを書き換えなくてもその場で結果が変わります。 「この茶色はどのテクスチャなのか」「この面はどのメッシュなのか」を確かめるのに、 いちばん手っ取り早い道具です。

  7. 次の1本へ

    花見団子の次は 月見団子.js（団子を積んで、触れ合う所を潰す）、 クッキー.js（皿に落として積む）あたりが読みやすい順です。 チョコレート.js と パンケーキ.js は分量が多いので後回しでかまいません。

9本は、こんなお菓子です

和菓子（花見団子・月見団子・たい焼き）、焼き菓子（クッキー・パンケーキ・ドーナツ・ロールケーキ）、 チョコレート（チョコレート・チョコバナナ）。 焼いたもの、蒸したり茹でたりしたもの、溶かして固めたものが混ざっています。 作り方が全部ちがうからです。一覧は図鑑にあります。 料理30本は、姉妹編の「たべもののつくりかた」にあります。

やってみよう
  1. 花見団子.js を Playground で動かし、右下のボタンで三色・みたらし・焼きを切り替えてみる。
  2. みたらしに切り替えたとき、色以外に何が変わるか（艶・たれの垂れ・形）を観察して1行で書く。
  3. 図鑑から好きなお菓子を3つ選んで、このサイトの中で動かしてみる。
  4. いくつかのファイルの先頭のコメントだけを読み比べて、共通する見出しを探す。
