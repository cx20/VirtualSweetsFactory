15Path

ゼリーの色は、中を通った距離で決まる

path length — 塗れない色の作り方

この章の3行まとめ
  • プリンの色は表面の色（アルベド）で決まります。ゼリーの色は違います。
  • ゼリーは中身の詰まった色ガラスで、見える色は光が中を何 cm 通ったかだけで決まります。
  • だから厚みを測ってシェーダに渡す。溝の底は薄いので明るく、山は厚いので濃い。

12章で、みたらしのたれを「色」ではなく「透明な層」として扱いました。 厚いところほど濃くなる、exp(−吸収係数 × 厚み) の話です。 ゼリーはその層がまるごと全部になったものです。ゼリー.js の冒頭にこうあります。

「プリンの色は『表面のアルベド』で決まる。ゼリーの色は違う。 ゼリーは中身の詰まった色ガラスで、見えている色は 透過光 = 背景 × exp(−σ · d) の d、つまり『その画素で光が中を何 cm 通ったか』でしか決まらない。 ここを『濃い緑のアルベド』で塗ると、必ず緑のプラスチックになる」

σ（シグマ）は 1cm あたりにどれだけ光が吸われるかで、赤・緑・青で別の値を持ちます。 ゼリー.js では、味ごとの色を σ で直接書くのではなく、 「基準の光路 4.5cm を通ったあとに何割残るか」（T0）で持たせています。写真から拾えるのはこの値だからです。

実験 — 塗る / 光路で解く

—

右の小さい図は、その画素で光が通った距離（白いほど長い）です。 「塗る」に切り替えると、縁と溝がいちばん濃くなるか、全体が同じ色のままになります。 どちらも、本物のゼリーでは起きません。

Babylon に、吸収の式をそのまま渡す

Babylon の PBR マテリアルには、屈折した光を中で色づける機能があり、その計算は 透過率 = tintColor ^ (thickness / tintColorAtDistance) です。 これはランベルト・ベールの法則そのものなので、

と入れれば、吸収の式がそのままシェーダで解かれます。 12章のたれは「エンジンの着色は厚み 0 で壊れるので CPU で焼く」でした。 同じ吸収の式でも、たれは表面の薄い膜で、ゼリーは中身の詰まった塊です。 ゼリーでは屈折（向こう側が歪んで見えること）も要るので、こちらはエンジンの機能を使っています。

厚みは、近似せずに測る

難しいのは thickness のほうです。「半径の2倍」や定数で済ませると、 シルエットのきわで厚みが最大になり、いちばん薄いはずの縁がいちばん濃くなります。 ゼリー.js は、断面の形（母線）の内側へ11本の光線を扇形に飛ばし（±75°）、 壁に当たるまでの長さを、法線に近い向きほど重く平均しています。 法線1本だけで測ると、肩の丸みのような「外から見れば薄いのに、法線の向きには胴を斜めに貫く」場所で 値が跳ねるからです。

測った値にも、もうひと手間あります。照明は上半球が明るいので、上を向いた面は 短い光路で光を集めます。測った弦長をそのまま使うと、天面は全高 5.2cm ぶんが入って いちばん濃くなり、写真といちばん食い違う場所になりました。 そこで上向きの面は topThin: 0.42 だけ薄く扱います。 この値は、写真の天面と胴の色の比から逆算したものです。

溝の底は、両側から削れている

菊型の溝は、単なる波ではありません。山は広く丸く、谷は細く深い。 cos をそのまま使うと洗濯板になるので、g0.6 にして谷だけを尖らせます。 さらに、彫った深さ d のぶん、溝の底の光路は 2d 短くなります（手前と奥で1回ずつ）。 ここを入れないと、いちばん明るいはずの谷がいちばん濃くなり、 ゼリー.js の言葉でいえば「緑に塗った菊の置物」になります。

溝を彫る向きにも工夫があります。母線の法線方向に彫ると、 天面（法線が真上）では高さの凹凸＝花びらに、側面（法線が横）では半径の凹凸＝溝に、自動的に変わる。 型は1枚のつながった面なので、天面と側面を別々に作ると位相がずれて、上と横で別の型に見えてしまいます。

つまずきポイント

ガラスの器を白く塗らない。 ガラスは光を反射と透過に振り分けるだけで、拡散反射をほとんど持ちません。 アルベドを白にすると乳白色のすりガラスになり、中のゼリーを覆ってしまいます。 無色のガラスはアルベドを黒にして、見えるものは映り込みと屈折だけにします。

プリンのカラメルは、そのままだと暗すぎる。 プリン.js のカラメルも同じ吸収の式で解いていますが、0.5mm の膜を往復するだけで橙、1.5mm で赤黒になるほど濃い。 ランベルト・ベールだけだと薄い縁まで濁った茶になるので、 膜の中で跳ね返る光を足す Saunderson の補正（内部反射率 0.45）を入れています。

透けるのに、不透明のパスで描く。 屈折は透明（アルファ）と独立に効くので、ゼリーは不透明メッシュのままにしてあります。 深度を書くので、ガラスの器の奥の壁が正しく隠れ、前後のソートにも悩みません。

やってみよう
  1. 「塗る」に切り替え、溝の谷と山のどちらが濃く見えるかを光路モードと見比べる。
  2. いちごにして σ の倍率を 2.5 まで上げ、縁と胴の色がどう分かれるか見る。
  3. メロンの T0 から σ を自分で計算し、本文の [0.27, 0.18, 0.67] と合うか確かめる。
  4. ゼリー.js で topThin を 0 にして Run し、天面の色がどう変わるか見る。
