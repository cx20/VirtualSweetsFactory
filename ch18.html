18Strand

綿菓子は、面ではなく3万本の線

strands — 表面の無いものの描き方

この章の3行まとめ
  • 綿菓子には、はっきりした表面がありません。見えているのは、細い砂糖の糸の重なりです。
  • 形の土台は回転体の曲面。その上に帯の向きに沿って短い糸を3万2千本、三角形ではなく線で描きます。
  • 糸だけだと中が空っぽに見えるので、半透明の芯を置き、その深度を先に書いて裏側の糸を隠します。

これまでの17章は、どれも「表面」を作る話でした。点を並べて三角形を張り、法線で明るさを決める。 綿菓子はそれが通じません。ふわふわの輪郭は、砂糖の糸が空中で重なってできています。 綿菓子.js の冒頭です。

「糸は曲面上を『帯に沿って』周方向に走らせる。……頂点には『表面上の点』と 『浮かせるベクトル（法線×浮き量）』を別々に持たせ、ふわふわ度はシェーダで掛けるだけにする。 糸だけだと中が空っぽに見えるので、少しだけ膨らませた曲面を半透明の『芯』として深度だけ先に書く」

土台は、帯を巻いた回転体

割り箸に巻き取った綿菓子は、下がすぼまって上が丸い。これは06章と同じ回転体の輪郭で書けます。 その上に、巻き取ったときのロープを巻いたような段々を乗せます。

v × 6.5 + φ/2π が一定の線は、1周するあいだに高さが 1/6.5 だけ下がる螺旋です。 この「帯の番号が一定の線」を等高線として使うのが、次の糸の工夫です。

実験 — 糸を帯に沿わせる / 芯で裏を隠す

—

「帯に沿わせる」を切ると、糸がばらばらの向きを向いて毛玉になります。 「芯の深度を先に書く」を切ると、向こう側の糸まで透けて見えて、中身の無い網のかごになります。 ふわふわ度は、糸を作り直さずに浮き量だけを掛け直しています。

糸は、帯の等高線に沿って走る

糸1本は 14 個の折れ線です。始点を曲面の上に選び、周方向に少しずつ進みながら、 高さを −1 / (2π × 帯の段数) の傾きで下げていく。すると糸は帯の螺旋と同じ向きを向き、 ロープの段々をなぞるように並びます。傾きには ±45% ほどの乱れを入れ、 7% の糸だけは「外へ飛び出す毛羽」として、長く・高く浮かせ、端をめくれさせます。 輪郭のふわふわは、この 7% が作っています。

始点の選び方にも注意が要ります。高さ v を一様に選ぶと、細い下のほうに糸が詰まりすぎる。 綿菓子.js はその高さの半径に比例する確率で受け入れて（棄却法）、面積あたりの本数を揃えています。

浮き量は、あとから掛ける

糸の頂点は「曲面の上の点」と「そこから浮かせるベクトル（法線 × 浮き量）」の2つを別々に持ちます。 シェーダでは p = position + normal * uFluff と、浮かせるベクトルに倍率を掛けて足すだけ。 だから GUI の「ふわふわ度」を動かしても、3万2千本を作り直す必要がありません。 17章のプリンで揺れの形を焼いておいたのと同じ考え方で、変わらないものを先に作り、変わるものは掛け算1回にしておきます。 ついでに、時間で少しだけ揺らして、糸が空気に浮いているように見せています。

線で描いて、芯で裏を隠す

糸は三角形ではなく、マテリアルを LineListDrawMode にした線として描きます。 1本ずつの不透明度は 0.40、端に行くほど薄くして、重なったところだけが白く見えるようにする。 ところが糸だけだと、向こう側の糸まで全部見えて、中身の無い網のかごになります。

そこで、曲面を少しだけ膨らませた芯を半透明で置き、needDepthPrePass = true で 色より先に深度だけ書いておきます。深度が書いてあれば、芯より奥の糸は自動的に描かれません。 芯は正面ほど不透明、縁ほど透明にしてあるので、輪郭は芯ではなく糸の毛羽で決まります。

つまずきポイント

糸に深度を書かせない。 半透明の糸が深度を書くと、先に描いた糸が後ろの糸を消してしまい、描く順番で見た目が変わります。 糸のマテリアルは disableDepthWrite = true、描く順番は alphaIndex で「芯 → 糸」と決めています。

線の太さは選べないと思っておく。 WebGL の線は、ほとんどの環境で太さ 1 画素に固定です。太さで表現しようとせず、 本数と不透明度で密度を作ります。3万2千本はそのための数です。

後処理に GUI まで巻き込まない。 ポストエフェクトを掛けると、右下のつまみまでにじみます。綿菓子.js は ui.layer.applyPostProcess = false で、GUI を後処理のあとに描いています。

やってみよう
  1. 「帯に沿わせる」を切り、何が「綿菓子らしさ」を作っていたのかを1行で書く。
  2. 「芯の深度を先に書く」を切って、ふわふわ度を 0 と 2.5 にしたときの違いを見る。
  3. 綿菓子.js で CFG.bands を 6.5 から 3 にして Run し、帯の段々がどう変わるか見る。
  4. 綿菓子.js の buildStrands() で stray の割合（0.07）を探し、0 にすると輪郭がどうなるか試す。
