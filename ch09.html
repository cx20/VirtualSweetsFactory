09SDF

ひとつの塊は、距離の場から削り出す

signed distance field + surface nets — 継ぎ目の無い形

この章の3行まとめ
  • 飴細工のウサギは、回しても掃引しても作れません。胴・頭・耳・脚が一つの塊だからです。
  • 部品を距離関数で書き、なめらかな最小値（smin）で溶かし合わせると、継ぎ目が消えます。
  • 格子で距離を測り、サーフェスネットで面を張る。格子の段は、ぼかすか面へ射影して消します。

06章では、断面を回して団子を作り、外形×縦断面でチョコを作りました。07章では軸に沿って断面を並べました。 ところが飴細工のウサギは、どちらでも作れません。飴細工.js の冒頭です。

「ウサギは距離関数（SDF）。胴・頭・耳・脚・尾・棒の付け根を楕円体と先細りカプセルで置き、 smooth min で一つの塊に溶かす（飴は一つの塊を引いて切って作るので、継ぎ目が無いのが本物らしい）」

距離関数（SDF）は、空間の点を渡すと「形の表面までどれだけ離れているか」を返す関数です。 外なら正、中なら負、ちょうど表面で 0。 球なら |p − 中心| − 半径 の1行です。 この形の良いところは、2つの形を足すのが「小さいほうを取る」だけで済むことです。 そして08章の団子で使った smin（なめらかな最小値）を使えば、つなぎ目が丸く溶けます。

k の値がそのまま作り方の記録になっています。胴どうしは 0.9 で大きく溶かし、 脚の付け根や足先は 0.12〜0.35 と小さくして、鋏で切り分けた段を残す。 耳の内側のくぼみは、楕円体を引き算（smax(外, −内)）して彫っています。

実験 — 距離の場から輪郭を拾う（2次元のサーフェスネット）

—

k を 0 にすると、耳・頭・胴のつなぎ目に角が出ます。 格子を粗くして「格子のまま」にすると輪郭がガタつき、 「場を1回ぼかす」（アイス.js）や「面へ射影する」（飴細工.js）で、それがどう消えるかが分かります。

格子で測って、面を張る

距離関数は「どの点でも測れる」だけで、三角形は持っていません。 そこで空間を格子に区切り、全部の格子点で距離を測ります。 隣り合う格子点で符号が変わる（外と中にまたがる）ところに、表面が通っている。

  1. 8つの角の符号が揃っていないセルにだけ、頂点を1つ置く。 位置は、符号の変わる辺の上の交点（距離が 0 になる所を直線で補間）の平均
  2. 符号が変わる辺1本ごとに、その辺を囲む4つのセルの頂点を四角形でつなぐ

これがサーフェスネット（Surface Nets）です。マーチングキューブより手順が短く、 セル1つに頂点1つなので、三角形がつぶれにくい。アイス.js も飴細工.js も、これを自前で書いています。

格子の段を消す、2つのやり方

セルの中の平均を取るだけだと、格子の向きにそった細かい段が出ます。 2本のサンプルは、これを別々のやり方で消しています。

  • アイス.js — 格子の距離の値を、軸ごとに 1:2:1 で1回ぼかしてから面を張る。 細部も少し丸まりますが、アイスはどうせあとでディッシャーの筋・めくれ・気泡を頂点に焼き込むので、 下地はなめらかなほうが都合がいい
  • 飴細工.js — 面を張ったあと、各頂点を距離の勾配に沿って表面へ押し戻す（2回）。 法線も勾配から取る。飴は手で引いたつるつるの面なので、元の距離関数の形をそのまま出したい

距離の場は、細部を焼く座標にもなる

アイス.js は、玉（少しつぶした球）と裾（外へ行くほど持ち上がる円盤）を smin でつないだ距離関数から始めます。 そのうえで、ディッシャーを引いた向き D・横 S・上 U の座標系を作り、 頂点ごとに「引いた筋」「削ぎ終わりのめくれ」「千切れた肌」「気泡の穴」を法線方向の変位として焼き込みます。 溶けは「下ほど細部が消えて沈み、裾が広がる」として、同じ頂点を書き直すだけです。

つまずきポイント

格子の全部の点を測ると遅い。 格子の間隔 0.065cm でウサギを包むと、測る点は150万を超えます。 飴細工.js は 4×4×4 のブロックの中心で1回だけ測り、表面から十分遠いブロックはその値で埋めます。 表面の近くだけ全部の点を測るので、手間はおよそ 1/10 です。

四角形の向きを決め打ちしない。 サーフェスネットの四角形は、外と中のどちら側から見ても作れてしまいます。 04章の「裏返ると消える」がそのまま起きるので、飴細工.js は辺の符号から外向きを決めて、 三角形ごとに外積で向きを確かめています。

距離関数は、smin を重ねると正しい距離ではなくなる。 符号（中か外か）は正しいままですが、値は「だいたいの距離」になります。 だから飴細工.js の射影は、1回で表面に届くとは考えず、2回繰り返して1歩の長さも制限しています。

やってみよう
  1. k を 0 → 0.3 → 1.4 と動かし、耳の付け根がどこから溶けすぎに見えるか探す。
  2. 格子の間隔を 0.8 にして、3つのモードの輪郭を見比べる。
  3. 飴細工.js で GRID を 0.065 から 0.15 にして Run し、組み立ての時間と見た目を比べる。
  4. アイス.js の makeScoopSDF() を読み、玉と裾をつなぐ smin の k（SCOOP.blend）を探す。
