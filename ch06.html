06Shape

回す、型で抜く

profile / outline × section — 断面と外形

この章の3行まとめ
  • 団子もプリンもドーナツも、横顔の折れ線を1本描いて、軸のまわりに回すだけで作れます。ろくろと同じです。
  • 回すのではなく外形（抜き型）と縦断面を掛け合わせるやり方もあります。チョコレートとクッキーがそれです。
  • どちらも、形を作る関数は1つ。お菓子の種類の違いは数値の表に入っています。

団子を作りたいとします。3Dの球を置いて潰す、ではありません。 まず紙に縦に切った断面の右半分を描きます。下から上へ、 中心からの距離（半径）が場所ごとにいくつになるかを並べた表です。 これを軸のまわりに1周ぶん回せば、立体ができます。これを回転体といいます。

型から抜いたプリンも同じです。プリン.js の母線（回す前の横顔）は、 骨格がたった4つの点でできています。上面の中心、上の縁、下の縁、底の中心。 つまり台形です。そこに角の丸めと、3つの小さな変形を足します。

点と点のあいだは直線でつなぐと角ばるので、なめらかな曲線で補います。 下の実験では Catmull-Rom スプラインを使っています。 「4つの点を見て、真ん中の2点のあいだをなめらかに通る」曲線です。 これで、10個前後の数字から曲面ができます。

実験 — 断面を引っぱると、立体が変わる

白い点を左右にドラッグ。これが半径の表です。

その断面を1周ぶん回した結果。ドラッグで回せます。

凹凸を 0 にすると工業製品、上げすぎると手びねりの粘土になります。 お菓子を切り替えると、そのお菓子の初期値に戻ります。手で丸める団子は 0.10、型から抜くプリンは 0.01。 プリンを 0.10 にすると、型抜きではなく積み重ねた輪に見えてきます。 栗饅頭は、本物は上から見ると楕円です。回転体を作ってから横に伸ばしています（→ 04章）。

断面は、円とは限らない — ドーナツ

回すのは、半径の表でなくてもかまいません。閉じた輪郭を回すと、穴のあいた輪になります。 ドーナツです。ただし、その輪郭を円にすると失敗します。ドーナツ.js のコメント：

「断面を単なる円（＝トーラス）にすると、それはドーナツではなく浮き輪になる。」 焼きドーナツの断面には、型の縁を越えて溢れた跡（外側面の水平な筋）、 膨れた面の外土手・谷・内土手、型の底に沿った平たい底、の3つが必ず出る。 ここを省くと上下をひっくり返しても同じに見え、焼き物に見えなくなる。

ドーナツ.js の断面は20個の点でできていて、1点ごとに「横・高さ」に加えて その点が型に接していたかどうか（0 = 型の面、1 = 膨れた面）を持っています。 この3つ目の数字が、そのまま焼き色と粗さの塗り分けに使われます（→ 10章）。 トップページで組み上がっていくドーナツが、この断面です。

型で抜く — 外形 × 縦断面

チョコレートのボンボンは、上から見ると丸や四角やハート、横から見るとドームです。 これは回転体ではありません。チョコレート.js は 外形（上から見た輪郭）と縦断面（横から見た形）を別々に定義して、掛け合わせています。 外形が抜き型、縦断面が生地の膨らみ方、と考えると分かりやすい。

7種類のクッキーは、1本の式と7行の数値

クッキー.js は同じ考え方をもう一歩進めて、丸・角丸四角・長方形・菊型を1本の式で扱います。 スーパー楕円に縦横比 aspect を掛け、菊型のときだけ周方向に波 cos(K·φ) を乗せる。 縦断面のほうは、上面のドーム dome と縁のふくらみ rimBulge の2つで決まります。

種類外形縦断面
サブレ半径 2.55、nExp 2（丸）厚み 0.98、dome 0.20
型押し半径 2.80、丸に 22 の波（scallopAmp 0.020）＝菊型厚み 0.70、dome 0.06（ほぼ平ら）
クラッカー半径 2.05、aspect 1.60、nExp 7（長方形）厚み 0.52、dome 0.02

形を作るコードは7種類で1つしかありません。違いは TYPES という表の数値だけです。 01章で「途中の1層だけ差し替えれば別のお菓子になる」と書いたのは、こういうことです。 新しいクッキーを足したいときは、関数を書かずに表に1行足します。

たい焼きも型で抜くお菓子ですが、外形は魚なのでスーパー楕円では書けません。 たい焼き.js は魚の輪郭を 2. Outline で引き、そこから輪郭までの距離を格子に焼いておき、 3. Relief で型の浮き彫り（鱗やヒレの筋）の高さを足しています。 外形が関数で書けないときは、「輪郭からどれだけ内側か」を表にしてしまえばよい。 この「距離」の考え方は、09章でもう一度出てきます。

つまずきポイント

断面の両端は、きちんと 0 まで絞ってください。 団子の上下を半径 0.2 で止めると、そこが穴になって中が見えます。 回転体には自動でフタが付かないからです。

同じ高さに半径を2つ置けません。 「t → r」の表は、ひとつの高さにひとつの半径しか持てません。 ドーナツの断面のようにぐるっと閉じた輪郭や、クッキーの縁のように外へ膨らんでから戻る形は、 (t, r) の2列ではなく (r, y) の2列で持つ必要があります。 プリン.js の ctrl も、ドーナツ.js の PROFILE_PTS も、この形です。

縁を直角にしないでください。 クッキー.js のコメント：「上面をそのまま垂直に落として底へつなぐと、縁が直角の 『削り出したプラスチック板』になる。実物の生地は焼成中に広がって縁が膨らむので、 最大径は側面の中ほどに来る」。

点の番号で刻まず、長さで刻んでください。 制御点の添字で v を割り振ると、丸めた縁のように点が密な所だけテクスチャが詰まって縞に見えます。 プリン.js とドーナツ.js は、輪郭を弧長（輪郭に沿った長さ）で等分し直しています。

やってみよう
  1. 「団子」の真ん中の点を外へ引っぱって、月見団子のように横に広い形にしてみる。
  2. 「プリン」のいちばん上の点を外へ出して、型から抜く前（上が広い）の形にしてみる。
  3. 凹凸を 0.4 にしたとき、どのお菓子なら許せてどれが嘘に見えるか決める。
  4. クッキー.js の TYPES から型押しとクラッカーの数値を探し、外形がどう違うか上の表と照らし合わせる。
